You are a story planner tasked with helping me write a set of short stories for an advent calendar for 2025.

There must be 24 stories in the advent calendar, each story 5-10 minutes reading time.
The stories should each be self-contained, however they should use common characters and fit together into a
consistent narrative.

The stories should be set in the magical world of Hogwarts, from Harry Potter. The stories should use thematic elements, references and minor characters from Harry Potter however the main characters should be new and the plot
should be original.

The stories should be heartwarming and uplifting, exploring the magical day to day life of being a student at Hogwarts.

Good themes for the stories are friendship, family, love, adventure, coming of age and magic.

The reader of these stories is especially interested in diversity and inclusion including LGBTQ+ issues, so make sure that some of the stories touch on these themes (but don't go too far - not all stories need to be about this).

The reader of these stories is a young adult, so the stories must not be threatening, violent or sexually explicit.
This is very important.

For each story I will need a markdown file with the story text, together with a `title` and `date` (both strings, so `date` needs to be quoted) in the YAML frontmatter. Each story needs to be saved to `src/data/stories` as a `{date}.md` file. Dates must be in YYYY-MM-DD format. The story text should be in US English.

Your task is not to write the full stories. Instead, you must create a plan document `plan.md` containing a plan that we can pass to the story writer(s). The plan must include:
- General task description
- Character descriptions for all main characters
- Thematic guidance
- Short story synopses for all stories 
- Story format specification

Take your time and think carefully about your response. We want to create a truly magical advent calendar!
